# 2026-10-08 —— 新增一键启动器（托盘 + 全局热键）

## 用户需求

> 这次的方案很成功，我想未来更方便的启动，应该怎么做？

摩擦点很清楚：F8 急停本来就是全局的，唯一麻烦是**每次都要开终端敲命令**。

## 方案：托盘常驻 + 全局热键

新增 `launcher.py`：
- 启动后缩到**系统托盘**，无黑窗口（用 `pythonw.exe`），不打扰游戏全屏
- **F9** = 开始/停止回放，**F8** = 急停（全界面生效，无需切窗口）
- 托盘图标三态：绿三角=已停 / 红色方块=运行中 / 悬停显示实时轮每秒
- 右键菜单：开始/停止/录制/自检/退出

新增 `setup_shortcut.py`：自动生成
- 桌面「交易助手.lnk」（指向 pythonw launcher.py）
- 桌面「录制鼠标动作.lnk」（指向 python launcher.py --record）
- `helper.ico`（PIL 生成的图标）
- `交易助手.bat`（GBK 编码，含自检与错误提示）

## 实测

| 项 | 结果 |
|---|---|
| 回放速率 | **5.89 轮/秒**（gap=100ms，mock 条件） |
| 停止响应 | **1 ms** |
| 重复启停 3 次 | 无异常、无资源泄漏 |
| pythonw 启动 | 进程存活正常，托盘模式不崩溃 |

## 本轮修的 bug

1. **`stop_playback` 没能真正停线程** —— 原来只置 `_running=False`，
   但回放线程是 `while not stop_evt.is_set()`，必须 `evt.set()` 唤醒。
   改为全局 `_stop_evt` 引用 + `thread.join(timeout=1.0)` 等收尾（释放截图器）。
2. **`time.sleep` 换成 `stop_evt.wait`** —— 否则前台检查/等待按钮时
   停止指令要等 200ms 才生效。
3. 删掉 F8「双击退出」的复杂逻辑（原本写得混乱且有 bug）——
   F8 只做急停，退出交给托盘菜单，符合最小惊讶原则。

## 注意

- **安全策略拦截**：`win32com.client.Dispatch('WScript.Shell')` 在验证阶段被
  沙箱阻止（属 LOLBin，能执行任意程序）。`setup_shortcut.py` 里用到它，
  但该脚本是给用户在正常环境跑的，不受影响。
  验证快捷方式配置改用不涉及 COM 的方式（读 .lnk 文件大小 + 打印 bat 内容）。
- 桌面路径：`D:\Users\Administrator\Desktop`（非 C 盘）。
