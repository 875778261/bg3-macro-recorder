# 2026-10-06

## mouse-script：BG3 交易面板自动化脚本

需求：高频重复「平衡报价」→「议价」两个点击。

技术方案（已与用户确认）：
- 路线：模板匹配 + 状态机，**不用纯坐标连点**（按钮有禁用灰态，盲点会空转）
- 环境：无边框/全屏窗口，物品已就绪，不解析对方回应，追求最高频率
- 急停：F8 + 鼠标甩左上角 + Ctrl+C；仅游戏前台时动作

### 本机实测环境（重要）
| 项 | 值 |
|---|---|
| 屏幕 | 3840x2160 |
| DPI 缩放 | **175%**（GetDpiForSystem=168） |
| 游戏窗口 | BG3，全屏铺满 (0,0) 3840x2160 |
| 游戏内部渲染 | 1920x1080 |
| 窗口标题 | `Baldur's Gate 3 (1920x1080) - (DX11) - (6 + 6 WT)` |

**踩坑要点**：DPI 175% 下未启用 DPI 感知时，Win32 `GetSystemMetrics` 返回
2194x1234 而实际是 3840x2160，差 175% 会让鼠标点击完全偏离。
`core.enable_dpi_awareness()` 必须在任何坐标计算前调用。

### 交付文件
- `core.py` — DPI感知截图(mss)、OpenCV模板匹配(含多尺度)、贝塞尔拟人化点击、急停
- `auto_bid.py` — 主循环，每轮重新定位；平衡报价亮/灰态亮度判定
- `calibrate.py` — 交互式框选采集模板 + `--price` 采集报价数字ROI
- `check.py` — 开跑前只读自检
- `config.json` / `README.md`

### 环境坑
- pip 默认源在国内极慢（opencv 44MB 挂了10分钟未完），**必须用清华镜像**
  `-i https://pypi.tuna.tsinghua.edu.cn/simple`，1分半完成
- 本环境 Git Bash 缺少 `ls`/`tail`/`head`/`mkdir` 等基础命令，且禁止 Bash 调
  PowerShell。改用 `python -c "import os; ..."` 列目录最稳。
