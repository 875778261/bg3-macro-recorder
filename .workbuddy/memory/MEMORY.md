# 项目长期记忆 · mouse-script

## 项目是什么

替用户在《博德之门3》(BG3) 里自动循环「平衡报价」→「议价」的桌面脚本。
纯单机、不联网、不读写游戏内存。

**完整交接信息见项目根目录 `HANDOFF.md`**（环境参数、架构、教训、待办）。

## 几条不可从代码看出的结论

1. **最终方案是「录制回放」而非图像识别** —— 两个按钮位置固定，
   视觉识别只在首次定位有价值。回放快 5 倍（5.0 vs 0.9 轮/秒）。
2. **判据标定必须采样正样本** —— 我曾拿禁用态的值当基准设阈值，
   而可点态的值与之同侧，导致脚本一直误判「禁用」、用户反馈「毫无反应」。
3. **需要图像标定时，先向用户要游戏截图** —— live 屏幕读到的数据是脏的
   （前台常有其他窗口叠加），我曾因此白费好几轮。
4. **运行状态只许 `_begin_session` / `_end_session` 两个函数改写** ——
   曾经回放线程的急停/异常退路径不复位状态，托盘于是「显示运行中、实际已停」，
   下一次「开始」被静默忽略（粘滞状态）。术语见 `CONTEXT.md`，
   决策见 `docs/adr/0001`。

## 日常用法

双击桌面「交易助手」→ 切到游戏按 `F6` 开始/停止（单键切换），`F10` 退出。
**急停 = 把光标甩到屏幕左上角**（不绑功能键：F8 与游戏冲突）。
状态验证一行：`.venv\Scripts\python.exe test_state_sync.py`（无头，15 项全绿）。

## 环境要点

3840x2160，**DPI 175%**（非 100%，坐标换算依赖 `enable_dpi_awareness()`）。
桌面在 `D:\Users\Administrator\Desktop`（非 C 盘）。

## 环境坑

- pip 必须用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- Git Bash 缺 `ls`/`mkdir` 等基础命令，且禁止 Bash 调 PowerShell；
  列目录用 `python -c "import os; ..."`
- 改含反引号的 Markdown 用 Edit 工具，**不要用 bash 内联脚本**
  （反引号会被解释，命令会真的执行，输出污染文档）
