# 热键用单键 F6 切换；急停不绑定任何功能键，只认「光标甩到左上角」

**背景**：原先 F9 启停、F8 急停。用户反馈 **F8 与 BG3 自身快捷键冲突**（按下时
游戏里也会触发动作），而 F9/F8 因为一个 `ctypes` 未导入的缺陷从未真正生效过 ——
所以这次等于重新定热键方案。

**决定**：
1. **F6 单键切换**开始 / 停止，不再设独立的急停功能键（用户明确要求「单键切换
   状态即可」）。托盘菜单里的「开始回放 / 停止回放」共用同一个 `toggle_playback()`。
2. **急停只认光标位置**：把光标甩到屏幕左上角（`core.cursor_in_panic_corner`）。
   `core.panic_stop_pressed()` 里对 F8 的判断已删除。理由同上 —— 不再把功能键
   绑到游戏也可能占用的键上。
3. 角落急停带**重新武装（re-arm）**语义：回放开始时若光标已经在角落（用户上一次
   就是甩角落停的），先不武装，等光标离开角落一次后才生效。否则第一轮循环立刻
   又命中急停，表现为「一启动就停」。

**考虑过的替代方案**：宽限期（启动后 N 毫秒内忽略角落）—— 需要拍一个魔法数字，
而且宽限期结束后光标若仍留在角落，照样会秒停；「离开一次再武装」是同一效果的
精确版本，无需调参。也考虑过启动时把光标挪到屏幕中心，但那会擅自动用户的鼠标。

**后果**：脚本自己会把光标移来移去，所以「武装」几乎立刻发生 —— 开始后第一击
就把光标带离角落。用户若在回放中把光标甩回左上角，急停照常生效。
